# API Key Parser

Android-приложение (Kotlin/Jetpack Compose) для парсинга и подбора API-ключей.

## Функции
- Управление провайдерами (base URL), автоизвлечение примера ключа из документации
- Ручной ввод шаблона ключа
- Валидация ключей, список моделей, баланс
- Импорт ключей из текста/файла, автоопределение дубликатов
- Подбор (bruteforce) ключей по набору символов и длине
- 32 цветовые темы, RU/EN, избранное, поиск/фильтр
- Шифрованное локальное хранение (EncryptedSharedPreferences)

## Сборка
GitHub Actions: push в main -> assembleDebug. APK в артефактах.
